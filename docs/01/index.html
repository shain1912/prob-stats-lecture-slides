바코드 스캐너 = 확률변수

  • 물건 → 숫자(가격)로 바꾸는 장치

이산확률변수와 확률분포

[비유] 피자 한 판 나누기

사진: maryseas4 / CC0

피자 한 판 = 전체 확률 1

  • 조각 하나 = X의 값 하나
  • 조각 크기 = 그 값의 확률
  • 조각 크기는 음수 불가 → 0 ≤ 확률 ≤ 1
  • 조각을 모두 모으면 한 판 → 확률의 합 = 1
1-2

이산확률변수와 확률분포

이산확률변수(discrete random variable)

· 이산확률변수: 취하는 값이 유한개이거나 자연수처럼 셀 수 있는 확률변수

· 확률질량함수(probability mass function): P(X = x₁) = p₁, …, P(X = xₙ) = pₙ

1-2

이산확률변수와 확률분포

이산확률변수의 확률분포의 성질

성질

① 0 ≤ p₁, p₂, …, pₙ ≤ 1

② p₁ + p₂ + … + pₙ = 1

예: 부품 품질 검사

  • 생산된 부품 10개 중 불량품 2개
  • 임의로 3개를 뽑아 검사할 때 불량품 수 X
  • X가 취하는 값: 0, 1, 2
  • 각 확률과 합 = 1 확인

사진: Robert Scoble / CC BY 2.0

1-2

이산확률변수와 확률분포

예: 불량품 수 X의 확률분포

P(X=0) = 7/15, P(X=1) = 7/15, P(X=2) = 1/15, 합 = 1.

연속확률변수(continuous random variable)

· 연속확률변수: 취하는 값이 어떤 범위에 속하는 모든 실수인 확률변수

· 확률 P(a ≤ X ≤ b) = 그래프 아래 넓이

1-3

연속확률변수와 확률밀도함수

[비유] 모래 더미

사진: cogdogblog / CC0

모래 더미 = 확률밀도함수의 그래프

  • 전체 모래 양 = 1
  • a ~ b 구간 위의 모래 양 = P(a ≤ X ≤ b)
  • 바늘 끝 한 점 위의 모래 양 = 0
  • → 한 점의 확률 P(X = a) = 0
1-3

연속확률변수와 확률밀도함수

확률밀도함수(probability density function)

1-3

연속확률변수와 확률밀도함수

확률밀도함수의 성질

α ≤ X ≤ β에서 정의된 y = f(x)

① f(x) ≥ 0

② 그래프 아래 전체 넓이 = 1

③ P(a ≤ X ≤ b) = a~b 구간의 넓이

주의

  • 한 점에서의 확률은 0: P(X = b) = 0
  • P(a ≤ X ≤ b) = P(a < X < b)
